# 🛒 AuraMart

A full-stack Java-based e-commerce web application built using Java, Maven, Apache Tomcat, HTML, CSS, JavaScript, and MySQL.

## 🚀 Features

* 👤 User Registration \& Login
* 🛍️ Product Listing
* 🔎 Product Browsing
* 🛒 Add to Cart
* ➕ Update Cart Quantity
* 💰 Order Price Calculation
* 📦 Place Order
* ✅ Order Confirmation
* ⭐ Customer Reviews
* 👨‍💼 Admin Product Management
* 📋 Admin Order Management
* 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

* Java 17
* Maven
* Apache Tomcat
* MySQL 8.0
* HTML5
* CSS3
* JavaScript
* JSP / Servlets

## ⚙️ Requirements

* Java JDK 17
* Apache Maven
* Apache Tomcat 11
* MySQL 8.0

## ▶️ How to Run

1. Clone the repository.
2. Configure the MySQL database.
3. Update database configuration according to your local environment.
4. Build the project using Maven.
5. Deploy the generated WAR file to Apache Tomcat.
6. Start Tomcat.
7. Open the application in your browser.

## 📌 Project

AuraMart is designed as a complete online shopping platform demonstrating Java web development, database integration, authentication, cart management, and order processing.
